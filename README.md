# Savings Goals Application

## Overview
The Savings Goals Application is a web-based tool designed to help users create, track, and manage their financial savings goals. The application is built using HTML, CSS, and JavaScript, and it stores user data locally in the browser.

## Project Structure
```
savings-planner
├── index.html        # Main HTML document for the application
├── css
│   └── styles.css    # CSS styles for the application
├── js
│   └── app.js        # JavaScript code for application functionality
└── README.md         # Documentation for the project
```

## Features
- Create new savings goals with a target amount and date.
- Track progress towards each goal.
- View a list of all savings goals.
- Delete goals as needed.
- Local storage support for saving user data without requiring an account.

## Getting Started
1. **Clone the repository**:
   ```
   git clone <repository-url>
   cd savings-planner
   ```

2. **Open `index.html`** in your web browser to view the application.

## Usage
- Fill out the form to add a new savings goal.
- Click "Add Goal" to save the goal.
- View your goals in the list below the form.
- Click "Open" to view details of a goal or "Delete" to remove it.
